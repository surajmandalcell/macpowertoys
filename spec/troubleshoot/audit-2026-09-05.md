# All-Tool Performance and Correctness Audit — 2026-09-05

## Scope and method

This audit covered the launcher and every built-in tool listed in `Tool.swift`: Awake, Color Picker, Text Extractor, Ruler, Cloud Sync, AI History, Logs, NetToys, System Care, System Monitor, and Input Devices. Dev Sync implementation was coordinator-owned and was observed only; no file under its excluded paths was changed.

The dynamic checks used a task-specific Debug product from `/tmp/mpt-dd-audit` without `MACPOWERTOYS_UI_TEST=1`. A launch probe recorded the first visible layer-0 window, `ps` sampled CPU and RSS once per second, tool routes were sampled three seconds after opening, and the product's standard output was counted by level for one minute. These are single-host snapshots, not causal benchmarks; RSS depends on process state. The first eight post samples used `e41ef3c`; the three completion samples used final code-bearing source `fab74c3`.
