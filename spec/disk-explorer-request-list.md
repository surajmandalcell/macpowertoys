# Partition Manager request list

Partition Manager (tool ID `disk-explorer`, formerly Diskman) is a dedicated
partition tool. The owner removed the Analyze section: folder scans,
treemap, rings, largest files, results, Choose Folder, scan caches, and
their settings no longer exist. The visual recipe is in `DESIGN.md`
(Partition Manager). Troubleshooting is in
`spec/troubleshoot/disk-explorer.md`.
