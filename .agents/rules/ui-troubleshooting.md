# UI Troubleshooting Compatibility Rule

The canonical troubleshooting knowledgebase starts at
`spec/troubleshoot/troubleshoot.md`. Load that index first, then read every topic
it routes for the current task before inspecting or changing implementation
files.

Do not add lessons here. Add verified symptom, cause, invariant, and runtime
check entries to the routed knowledgebase topic and keep the main index current.
